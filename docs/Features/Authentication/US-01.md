### 🧠 Story ID: US-01
**Feature**: Register user using Star Plus Games

### Actors 🧑‍💻
- Designer

***As a*** designer, 
***I want to*** sign up using Star Plus Games,
***So that*** I can login to Intrastation

### 🗃️ Data Dictionary
- Name
- Email
- Password
- Confirm Password

### 🎬 Normal Scenario
- Designer enters sign up fields
- System validates inputs then registers a new user
- System navigates notifies user he created accout successfuly then navigates to login

### ↩️ Aletrnative Scenario
- Designer enters sign up fields
- System validates inputs but find invalid inputs
- System notifies user with the wrong inputs

### ✔️ Acceptance Criteria
- Name cannot be empty
- Email must be valid and unique
- Password must be longer than 7 characters, contains capital and lower letters and at least one digit
- Password must be confirmed
